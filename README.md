# 💖 Birthday Surprise Website

A romantic, personalized birthday surprise website created with love. This interactive website is designed to make a special person feel loved through memories, heartfelt messages, music, and beautiful animations.

## ✨ Features

- 🔐 **Secret Passcode:** Unlock a personalized surprise.
- 💗 **Romantic Landing Page:** A beautiful design with a soft pink gradient and elegant typography.
- 📖 **Our Story:** Special messages celebrating your journey together.
- 📸 **Memories Gallery:** A collection of meaningful photos and moments.
- 💌 **Love Letter:** A heartfelt personal message.
- 💕 **Reasons I Love You:** Sweet reasons to make someone smile.
- 🎁 **Interactive Final Surprise:** An animated reveal with a romantic message.
- 🎵 **Background Music:** Music to create a special atmosphere.
- 💖 **Floating Hearts:** Cute animations throughout the experience.
- 📱 **Responsive Design:** Designed to work on desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages for hosting

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/birthday-surprise.git
   ```

2. Open the project folder:

   ```bash
   cd birthday-surprise
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🌐 Deploy with GitHub Pages

1. Open your GitHub repository.
2. Go to **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Click **Save**.
6. Once deployment finishes, visit:

   `https://YOUR-USERNAME.github.io/birthday-surprise/`

Replace `YOUR-USERNAME` with your GitHub username.
